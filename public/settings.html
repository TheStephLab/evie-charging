How to get a Microsoft Teams webhook URL
  1. In Teams, open the channel EVIE should post to, then choose ⋯ (More options) → Workflows.
  2. Pick the template Send webhook alerts to a channel (older name: Post to a channel when a webhook request is received).
  3. Name it “EVIE”, confirm the team and channel, then choose Add workflow.
  4. Copy the URL it shows and paste it below. Treat it like a password: anyone with it can post to the channel.

Slack and Google Chat incoming webhooks work too; EVIE sends them plain text.
